Latest Release

Giveaway Shuffle v3.0

Major update focused on winner placements, rerolls, stability improvements, and giveaway management.

🏆 Multi-Place Winner System

Multi-winner giveaways now properly assign placements:

  • 1st Place
  • 2nd Place
  • 3rd Place
  • and more

Each placement is drawn individually instead of stopping with multiple finalists remaining.

  • 1st place draws from the Top 10
  • 2nd place draws from the remaining Top 9
  • 3rd place draws from the remaining Top 8

🔄 Advanced Reroll Improvements

  • Replacement rerolls now preserve original placements.
  • If 2nd place is rerolled, the replacement becomes the new 2nd place winner.
  • Previous reroll exclusions stay excluded during future replacement rerolls.
  • Full rerolls correctly reset the entire contestant pool.
  • Better reroll result tracking.

🧾 /sentry Improvements

  • Bulk entry support has been merged directly into /sentry.
  • Cleaner entry workflow for single and bulk entries.

📜 /slist Improvements

  • View active giveaways.
  • View closed giveaways.
  • View past drawings.
  • View winner and reroll history.

🛡️ Stability & Protection Improvements

  • Improved permission/access handling.
  • Better giveaway management protection.
  • Safer reroll handling.
  • Drawings continue safely even if live reveal messages are deleted during the drawing process.

⚙️ Commands

  • /screate — Create giveaway
  • /sentry — Add single or bulk entries
  • /sremove — Remove contestant
  • /stime — Edit giveaway times
  • /sclose — Close entries
  • /sdraw — Run drawing
  • /sreroll — Reroll winners
  • /slist — View giveaways/history
  • /sdelete — Delete giveaway
  • /shelp — Show commands

Version 2.1

May 2026

Recovery Update

This update makes giveaways more reliable and resilient.

🔄 Recovery System

  • If a giveaway post is accidentally deleted, it will automatically restore.

🔐 Permission Awareness

  • If the bot temporarily loses access, it will restore the giveaway once permissions are fixed.

Version 2.01

April 2026

Minor Update

  • Periodic giveaway updates now edit the original giveaway post instead of creating extra update messages.
  • Cleaner giveaway channels with less repeated bot activity.
  • The original giveaway message now stays current with updated entries and status.

Important Note

  • Keep the original giveaway post created when the giveaway started.
  • Newer repeated update posts from older versions may be manually removed if desired.
  • Active giveaways and drawings are unaffected.
